# NextRide

Responsive campus ride coordination demo for FUTMINNA students. Built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. No build step is required.

## Demo behavior

Navigation, sample sign-in, vehicle filters, seat reporting, trip windows, group states, and the boarding pass are front-end demonstrations. They do not connect to a backend. The QR pattern is illustrative and cannot be scanned.
